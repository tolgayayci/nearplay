# Compilation

NEAR Playground compiles your Rust code to WebAssembly (WASM) using `cargo-near`, the official NEAR build tool.

## How to Compile

Click the **Compile** button or press `Ctrl/Cmd + B`.

<img src="/images/compile-button.png" alt="Compile button" />

## Compilation Output

After compilation, you'll see:

### Success

```
Compiling contract...
Build successful!

Contract size: 142.5 KB
ABI methods found: 5
```

- **Contract size** - The WASM file size (smaller is better for gas costs)
- **ABI methods** - Public functions detected in your contract

### Errors

If compilation fails, you'll see the error messages:

```
error[E0425]: cannot find value `foo` in this scope
  --> src/lib.rs:15:9
   |
15 |         foo
   |         ^^^ not found in this scope
```

Errors are also highlighted in the editor with red underlines.

<img src="/images/compile-error.png" alt="Compilation error" />

## What Happens During Compilation

1. Your Rust code is sent to our build server
2. `cargo-near` compiles it to WASM
3. The contract is optimized for size
4. ABI (Application Binary Interface) is extracted
5. Results are sent back to your browser

## Contract Size

Smaller contracts cost less gas to deploy. Tips to reduce size:

- Remove unused dependencies
- Use `#[near(contract_state)]` instead of manual serialization
- Avoid large static strings

<Note>
The maximum contract size on NEAR is 4MB, but most contracts are under 500KB.
</Note>

## ABI Generation

The compiler automatically extracts your contract's ABI, which includes:

- Method names
- Parameter types
- Return types
- View vs call classification

This ABI powers the auto-generated Contract Interface.
