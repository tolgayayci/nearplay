# Contract Interface

After deployment, NEAR Playground generates a UI to interact with your contract methods.

<img src="/images/contract-interface.png" alt="Contract interface" />

## Method Types

### View Methods

- **Free** - No gas cost
- **Read-only** - Cannot modify state
- **Instant** - Results appear immediately

Marked with an eye icon and "view" badge.

```rust
// This is a view method
pub fn get_value(&self) -> i32 {
    self.value
}
```

### Call Methods

- **Costs gas** - Requires a transaction
- **Can modify state** - Changes are permanent
- **May require deposit** - For payable methods

Marked with a play icon and "call" badge.

```rust
// This is a call method
pub fn increment(&mut self) {
    self.value += 1;
}
```

### Payable Methods

Methods that accept NEAR tokens show a deposit field.

```rust
#[payable]
pub fn deposit(&mut self) {
    let amount = env::attached_deposit();
    // ...
}
```

## Using the Interface

### Calling a Method

1. Find the method in the list
2. Fill in any parameters
3. Click the method button
4. View the result

<img src="/images/call-method.png" alt="Calling a method" />

### Parameter Types

The UI automatically creates appropriate inputs for:

| Type | Input |
|------|-------|
| `String` | Text field |
| `u32`, `i32`, `u64`, `i64` | Number field |
| `u128` | Number field (for token amounts) |
| `bool` | Checkbox |
| `AccountId` | Text field |
| JSON objects | JSON editor |

### Results

Results appear below the method:

- **View methods**: Show the returned value
- **Call methods**: Show transaction hash and link to explorer

## Selecting a Deployment

If you've deployed multiple times, use the dropdown to switch between deployments.

<img src="/images/deployment-selector.png" alt="Deployment selector" />

Each deployment shows:
- Contract address
- Deployment time
- Verification status
